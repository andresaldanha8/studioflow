# Testes do StudioFlow

## Objetivo

Esta pasta contém todos os testes automatizados do StudioFlow.

Os testes garantem que novas funcionalidades não quebrem recursos já existentes.

---

# Estrutura

tests/

├── api/
→ Testes das APIs do backend.

├── e2e/
→ Testes completos simulando o uso do sistema.

---

# Execução

Os testes serão executados através de comandos npm.

Exemplos futuros:

npm run test:api

npm run test:e2e

npm run test

---

# Objetivo Final

Todo recurso novo deverá possuir pelo menos um teste automatizado antes de ser considerado concluído.
